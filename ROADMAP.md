# Roadmap

| Phase | Scope | Status |
|---|---|---|
| **M0 - Project Foundation** | Repository, reproducible environment, architecture, testing and CI infrastructure, persistent documentation and conventions | Completed |
| **M1 - Computer Vision & Live Visualization** | Webcam acquisition, MediaPipe hand tracking, skeleton and landmark overlay, motion/vector engine, desktop UI, stability and performance verification | See [PROJECT_STATUS.md](PROJECT_STATUS.md) |
| **Integration Audit 001** | Whole-codebase audit after M0 and M1 | See [docs/audits](docs/audits) |
| **M2 - Gesture Recognition Engine** | Swipes, thumbs-up, pinch and similar gestures built on the motion engine; confidence and debouncing; gesture visualization | Not started |
| **M3 - YouTube Integration** | YouTube Shorts navigation (next/previous), like, play/pause | Not started |
| **M4 - Windows Control Engine** | Switching between applications with directional swipes; desktop interactions | Not started |
| **Integration Audit 002** | Whole-codebase audit after M2 to M4 | Not started |
| **M5 - Desktop UX & Content Creator Mode** | Floating webcam overlay, customizable gesture mappings, persisted settings, polish | Not started |
| **M6 - Public Release** | Packaging (Windows installer or bundle), licensing compliance for bundled Qt and the model, release documentation | Not started |

Each milestone starts only after a new engineering brief is approved by the project owner.
